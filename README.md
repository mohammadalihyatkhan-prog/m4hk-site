# m4hk.com

The website of the artist M4HK (Mohammad Ali Hyat Khan), Lahore.

This repository holds the finished pages and pictures only: plain HTML, one stylesheet, one small
script and images. It is a draft and is not yet live at m4hk.com.

The pictures and texts belong to the artists (joint works: M4HK and Ujala Khan) and are not licensed
for reuse. The fonts, Newsreader and IBM Plex Mono, are under the SIL Open Font License; their
licence texts are in `assets/fonts`.
